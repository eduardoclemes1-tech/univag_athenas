# Política de Segurança

## Versões Suportadas

Atualmente, apenas a versão principal ativa na branch `main` recebe atualizações e correções de segurança.

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x (main)   | :white_check_mark: |

## Relatando Vulnerabilidades

A segurança dos dados acadêmicos e a privacidade dos estudantes e monitores da plataforma são prioridades absolutas.

Se você descobrir alguma vulnerabilidade de segurança:
1. **Não** abra uma issue pública detalhando a falha ou vetor de exploração.
2. Envie um relatório detalhado diretamente para o mantenedor responsável via e-mail ou abra um [GitHub Security Advisory](https://github.com/eduardoclemes1-tech/univag_athenas/security/advisories/new) privado.
3. Inclua etapas de reprodução, impacto estimado e, se possível, uma sugestão de correção defensiva.

Agradecemos a colaboração responsável para mantermos a comunidade segura.
